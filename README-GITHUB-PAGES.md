# Soli Medical على GitHub Pages

## الملفات المطلوبة

ارفع `index.html` و`manifest.webmanifest` و`sw.js` ومجلد `icons` إلى جذر المستودع. ملف `sw.js` يخزن ملفات الواجهة فقط ولا يخزن بيانات Firestore أو استجابات API الحساسة.

## تفعيل GitHub Pages

من إعدادات المستودع افتح **Settings → Pages**، ثم اختر النشر من فرع `main` ومن مجلد `/ (root)`. بعد النشر افتح الرابط الناتج باستخدام HTTPS.

## تثبيت التطبيق

على الهاتف افتح رابط الموقع في Chrome أو Safari، ثم اختر **إضافة إلى الشاشة الرئيسية** أو **Install app**. يجب أن يكون الموقع على HTTPS حتى يعمل service worker والتثبيت كتطبيق مستقل.

## ملاحظة مراجعة

تم فحص JavaScript المضمن بنجاح، ولم توجد معرفات HTML مكررة. يوجد في النسخة الحالية رابط قديم إلى `setup-admin.html`، لكن هذا الملف غير مرفق ضمن الملفات الحالية؛ يجب إضافة ملفه الأصلي إلى المستودع إذا كانت وظيفة استعادة مدير النظام مطلوبة.
